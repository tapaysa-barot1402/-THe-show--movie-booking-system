# -THe-show--movie-booking-system
A Python-based movie booking application with separate User and Admin interfaces, featuring mood-based movie recommendations, customizable seat booking, restaurant food ordering, user profiles, and automated bill generation using Tkinter and MySQL

The Show is a desktop-based movie booking application developed using Python, Tkinter, and MySQL. It provides an interactive movie-booking experience with separate User and Admin interfaces, personalized movie recommendations, customizable ticket booking, restaurant food ordering, and automated bill generation.

#Features
User Interface
Create and manage a user profile
Browse available movies
Get movie recommendations based on mood
Book movie tickets with customizable preferences
Choose between AC / Non-AC options
Select seat preferences
Specify booking preferences such as number of children and couples
Order food from the in-app restaurant
View booking and food-order details
Generate a final bill based on the selected services
# Admin Interface
Dedicated Admin interface for managing the application
Manage movie and restaurant-related information
Maintain the data required for movie bookings and food orders
# Mood-Based Movie Recommendation

The application allows users to enter their mood and receive movie suggestions based on their selected mood, making movie discovery more personalized.

# Movie Booking

Users can select a movie and customize their booking according to their preferences, including seating and other booking options.

# Restaurant & Food Ordering

Users can browse food options available through the in-app restaurant and add their selections to their order.

# Automated Billing

After completing the movie booking and food selection, the application generates a final bill containing the selected services and their corresponding charges.
